# Operational Runbooks

## EKS Cluster Recovery

1. Validate node health
2. Verify control plane status
3. Check autoscaling groups
4. Restore workloads

## Failed Deployment Rollback

1. Review deployment logs
2. Identify failing release
3. Roll back Kubernetes deployment
4. Validate application health

## High CPU Usage

1. Inspect Prometheus metrics
2. Identify affected workloads
3. Scale deployments
4. Review autoscaling configuration
