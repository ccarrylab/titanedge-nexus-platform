# Observability Stack

## Monitoring

The platform uses:

- Prometheus
- Grafana
- CloudWatch
- Datadog

## Metrics Collection

Metrics include:

- Kubernetes node health
- API latency
- Pod resource utilization
- Application availability

## Logging

Centralized logging pipelines aggregate:

- Application logs
- Kubernetes events
- AWS service logs

## Alerting

Alerts are routed through:

- PagerDuty
- Slack
- CloudWatch alarms
